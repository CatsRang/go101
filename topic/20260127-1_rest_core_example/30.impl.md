## Technical Notes
- **Context Merging**: The `ContextPropagator` middleware ensures that handlers are responsive to both client disconnects and server shutdown signals.
- **Graceful Shutdown**: The shutdown sequence stops the HTTP server first (preventing new requests) and then drains/stops the worker pool.
- **Naming Collisions**: Renamed `ExampleJob.Name` field to `JobName` to avoid conflict with the `worker.Job` interface method `Name()`.
- **Import Aliasing**: Used `middlewareZap` as an alias for `pkg/middleware` to avoid collision with Echo's built-in `middleware` package.
