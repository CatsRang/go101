# Go 프로그래밍 언어 학습 커리큘럼 (Go 1.20-1.25)

## 개요

이 종합 커리큘럼은 Go의 기초부터 고급 실제 애플리케이션까지 다루며, Go 1.20부터 1.25까지의 최신 기능을 포함합니다. 이 커리큘럼은 구조화된 로깅, 이터레이터, 향상된 라우팅 및 최신 성능 최적화를 포함한 현대적인 Go 개발 관행을 강조합니다.

***

## 1단계: 기초 (2-3주)

### 1주차: 시작하기 및 기본 문법

**핵심 개념**[^1][^2][^3]

- Go 1.25 설치 및 개발 환경 설정
- Go 작업 공간 및 모듈 이해
- 기본 문법 및 프로그램 구조 (`package main`, imports)
- 변수, 상수 및 데이터 타입 (int, float, string, bool)
- `:=` 연산자를 사용한 타입 추론
- 기본 입출력 연산 (`fmt` 패키지)

**주요 토픽**

- 첫 "Hello, World!" 프로그램 작성
- Go의 컴파일 과정 이해
- `go run`, `go build`, `go install` 명령어 사용
- `gofmt` 및 `goimports`를 사용한 코드 서식 지정[^4]

**실습 과제**
사용자 입력을 받아 기본 산술 연산을 수행하는 간단한 명령줄 계산기를 만드세요.

### 2주차: 제어 흐름 및 자료 구조

**핵심 개념**[^2][^3][^1]

- 제어 구조: `if`, `else`, `switch`
- 루프: `for` (Go의 유일한 루프 구문)
- **Go 1.22 이상: 정수에 대한 range**[^5][^6][^7]
- 배열 및 슬라이스 (동적 배열)
- 맵 (키-값 쌍)
- Range 순회
- 문자열 조작

**최신 Go 1.22+ 기능**[^6][^7][^5]

```go
// 정수에 대한 range (Go 1.22+)
for i := range 10 {
    fmt.Println(10 - i)
}
fmt.Println("go1.22 has lift-off!")
```

**주요 토픽**

- 슬라이스 용량 및 길이 이해
- 슬라이스 연산: append, copy, slicing
- 맵 연산: 삽입, 삭제, 순회
- 리소스 정리를 위한 `defer` 문

**실습 과제**
맵과 슬라이스를 사용하여 연락처 정보를 저장하고 검색하는 연락처 관리 시스템을 구축하세요.

### 3주차: 함수 및 포인터

**핵심 개념**[^3][^8][^1]

- 함수 선언 및 호출
- 다중 반환 값
- 이름 있는 반환 값
- 가변 인자 함수
- 익명 함수 및 클로저
- 포인터 및 메모리 주소 이해
- 포인터 연산 및 역참조

**Go 1.21+ 내장 함수**[^9][^10][^11][^4]

- **`min` 및 `max` 함수**: 고정된 수의 인수 중 최소/최대값 계산
- **`clear` 함수**: 모든 맵 요소 삭제 또는 모든 슬라이스 요소 제로화

```go
// Go 1.21+ 내장 함수
result := min(100, 42, 73)        // 42
result := max(5.5, 3.14, 9.81)    // 9.81

m := map[string]int{"a": 1, "b": 2}
clear(m)  // m은 이제 비어있음

s := []int{1, 2, 3}
clear(s)  // s는 이제 [0, 0, 0]
```

**실습 과제**
새로운 내장 함수를 사용하여 단어 수 계산, 문자 빈도 분석 및 텍스트 변환을 위한 텍스트 처리 라이브러리를 만드세요.

**핵심 개념**[^1][^2][^3]

- 제로 값 이해

**Go 1.20+ 기능**[^12][^13][^14]

**주요 토픽**

- JSON/XML 직렬화를 위한 구조체 태그
- 익명 구조체
- 메서드 집합 및 리시버 타입

**실습 과제**
구조체와 메서드를 사용하여 제품, 카테고리, 공급 업체가 있는 간단한 재고 관리 시스템을 구축하세요.

**핵심 개념**[^16][^3][^15][^1]

### 6주차: 오류 처리

**핵심 개념**[^17][^18][^19][^20][^21]

- Go의 오류 처리 철학
- `error` 인터페이스
- 사용자 정의 오류 생성
- **Go 1.20+: 다중 오류 래핑**[^22][^13][^12]
- `fmt.Errorf` 및 `%w`를 사용한 오류 래핑
- **다중 오류 래핑을 위한 `errors.Join()`**[^22]
- `panic` 및 `recover` 메커니즘
- 정리 작업을 위한 `defer`

**최신 오류 처리 (Go 1.20+)**[^13][^12][^22]

```go
// 다중 오류 래핑 (Go 1.20+)
err1 := errors.New("첫 번째 오류")
err2 := errors.New("두 번째 오류")

// 다중 오류 래핑
multiErr := errors.Join(err1, err2)

// 또는 fmt.Errorf 사용
err := fmt.Errorf("작업 실패: %w, %w", err1, err2)
```

**주요 토픽**

- `panic` 사용 시점과 오류 반환 시점[^21]
- 적절한 오류 컨텍스트 및 래핑
- 관용적인 오류 처리
- 오류 처리 모범 사례[^21]

**실습 과제**
적절한 다중 오류 래핑으로 다양한 오류 시나리오를 정상적으로 처리하는 파일 프로세서를 구축하세요.

### 7주차: 패키지 및 모듈

**핵심 개념**[^23][^24][^25][^26][^2]

- Go 패키지 이해
- 패키지 명명 규칙
- 공개(Exported) 식별자와 비공개(Unexported) 식별자
- Go 모듈 (`go.mod` 및 `go.sum`)
- `go get`을 사용한 종속성 관리
- 유의적 버전 부여
- **Go 1.24+: `go get -tool`을 사용한 도구 종속성**[^27][^28]

**최신 모듈 관리 (Go 1.24+)**[^28][^29][^27]

```go
// 도구 종속성 추적 (Go 1.24+)
go get -tool github.com/golangci/golangci-lint@latest

// tool 지시문으로 선언된 도구 실행
go tool golangci-lint run
```

**주요 토픽**

- `go mod tidy`로 종속성 관리[^24][^23]
- 종속성 업데이트: `go get -u`
- 종속성 벤더링
- 재사용 가능한 패키지 생성
- GOAUTH를 사용한 비공개 모듈 저장소[^29]

**실습 과제**
문자열 조작, 파일 처리 및 데이터 유효성 검사 기능이 있는 유틸리티 패키지를 만든 다음 모듈로 게시하세요.
